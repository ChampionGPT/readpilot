# app 模块声明

**一旦我所属的文件夹有所变化，请更新我。**

本目录采用 Next.js App Router 模式，主要存放网页组件页面及后端 API 路由。

- `globals.css`: [地位：基础样式] - [功能：注入 Tailwind 核心引擎与全局 CSS 变量体系]
- `layout.tsx`: [地位：根布局] - [功能：定义整个 HTML 的包裹元素与基础 Font/Meta 设置]
- `page.tsx`: [地位：根主页] - [功能：渲染 ReadPilot 核心的三栏并发阅读交互视图]
- `api/`: [地位：服务端点] - [功能：承接来自前端的调用或提供外部集成接口]
