# articles/ — 深度文章模块

> 一旦我所属的文件夹有所变化，请更新我。

独立文章的导入、列表展示、沉浸式阅读视图。文章为平级实体，不隶属于书籍。

| 文件 | 地位 | 功能 |
|------|------|------|
| `ArticleImportModal.tsx` | 入口组件 | 文章导入表单浮层（标题/URL/正文/作者） |
| `ArticlesListView.tsx` | 中央主面板 | 文章列表视图，含空状态引导 + 乐观删除 |
| `ArticleReadView.tsx` | 中央主面板 | 沉浸式文章阅读视图（serif排版 + 阅读状态标记） |
| `ArticlesPanel.tsx` | 侧边栏面板 | 侧边栏文章缩略列表（状态圆点 + 高亮选中） |
